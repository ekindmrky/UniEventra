# UniEventra

## Project Description

UniEventra is a web-based event management platform designed for university students and club representatives. Students can explore, filter, and join events, while organizers can create and manage events.

## Tech Stack

* Next.js
* TypeScript
* Supabase
* Tailwind CSS
* Vercel

## Local Setup

To run the project locally:

1. Clone the repository:
   git clone https://github.com/ekindmrky/UniEventra

2. Install dependencies:
   npm install

3. Run the project:
   npm run dev

## Deployment

The application is deployed on Vercel:
https://uni-eventra-eta.vercel.app
